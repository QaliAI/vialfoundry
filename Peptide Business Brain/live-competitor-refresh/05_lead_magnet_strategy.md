## Recommended funnel sequence

### Before payment / current preview

1. Homepage CTA: `Request Documentation Checklist`
2. Catalog CTA: `Request Full Catalog Access`
3. Product CTA: `Request Documentation Packet`
4. Quality page CTA: `Download COA Review Checklist`
5. Admin tracks lead source and requested documentation type.

### After payment

1. Build PDF lead magnets.
2. Add email confirmation / delivery automation.
3. Add source tracking to inquiry records.
4. Add downloadable “sample COA checklist” from trust pages.
5. Add wholesale account request route.

### After processor / launch readiness

1. Consider restrained free-shipping threshold only if operations support it.
2. Consider newsletter for “batch documentation updates,” not generic discounts.
3. Launch curated affiliate/referral only with claim guardrails and monitoring.

## Copy examples to use safely

- `Get the research peptide documentation checklist.`
- `Request full catalog access for documentation review.`
- `Ask for COA, HPLC, MS, or batch documentation status.`
- `Receive documentation-focused updates and availability notices.`

## Copy to avoid

- `Save on your first order` before payment/fulfillment is real.
- Any outcome-oriented product guide.
- Any “protocol,” “stack,” or “use” guide.
- “Guaranteed approval” for wholesale, payment, or account access.
- “FDA compliant,” “legal,” or “processor approved.”

## Bottom-line recommendation

Use **documentation downloads + catalog/documentation requests** instead of discount-first lead capture. It is more premium, lower risk, and directly supports the inquiry-first strategy.
